# Adam para VS Code

Abra o painel do Adam na barra lateral, configure sua chave de API (comando "Adam: Configurar chave de API") e peça o que quiser: corrigir bugs, implementar melhorias, explicar código.
O Adam lê o projeto sozinho e pede sua aprovação antes de editar arquivos ou rodar comandos.

Cérebro: Adam Pro (servidor) com o Ollama local (qwen2.5 em http://localhost:11434) de reserva. Altere em Configurações → Adam.
